# MikroWizard Front Changelog

## Version 1.3.0

### Major Milestones
- **Angular 18 Upgrade:** Migration to the latest Angular framework for improved performance and stability.
- **PrimeNG Migration:** Successfully replaced the deprecated `gui-grid` with PrimeNG's advanced table architecture, enhancing data presentation and interaction.

### New Features (Pro)
- **WireGuard VPN UI:** Dedicated management interface for the integrated WireGuard server, peer configuration, and device mapping.
- **Sequences UI:** New interface for creating and managing chained execution of snippets and automated tasks.
- **Custom Syslog Regex UI:** Added a regular expression builder for defining custom log parsing rules.
- **Custom Alerts UI:** New management panel for creating and monitoring fully custom alerts based on syslog or task output.

### UI/UX Improvements
- **Interface Redesign:** Modernized and refined the UI across several core modules:
  - Settings
  - Backups Management
  - User Management
  - Password Vault (Pro)
  - Sync & Clone (Pro)
  - Device Groups
- **Network Map Enhancements:** Improved topology rendering and added reset buttons for easier map management.
- **General Styling:** Application-wide UI/UX enhancements for a more premium and responsive feel.
- **Better License Feedback:** Improved handling and display of Pro license expiration and registration status.

## Version 1.2.0

### New Features
- **Network Map (Pro):** Initial release of the automated live network topology map.
- **Proxy WebFig (Pro):** Support for secure remote WebFig access with auto-login.
- **Bulk Device Import:** Added support for importing devices via CSV.
- **Advanced Task Scheduling:** Integration of predefined cron examples in the Tasks page.
- **Device Management:** Added WebFig access button directly in the device list.

### Improvements
- **Device Details:** Refined layout for active sessions, DHCP leases, and device logs.
- **User Permissions:** Enhanced group-based permission management.
- **Stability:** General bug fixes and UI refinements.
