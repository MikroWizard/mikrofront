How Alert Channels Work

This section allows you, the Administrator, to globally enable and configure supported notification services for the entire MikroWizard platform.

  • Enable/Disable: Only services enabled here will be visible to end-users when they create their own Notification Channels in the Alerts tab.
  • Global Configuration: Some services (like Slack or Telegram) require an Administrator to configure an API Token or Webhook URL globally. Enter those credentials here.
  • User Input: Other services (like Ntfy or Pushover) only require user-specific credentials. End-users will provide those when they set up their channel.
